# Installation Guide

Follow these steps to install the tool on your system.

...

## Prerequisites

- Ensure you have [Node.js](https://nodejs.org/) installed on your machine.
- Make sure you have a package manager like [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/) installed.

## Installation Steps

1. **Clone the Repository**:
   Open your terminal and run the following command to clone the repository:

   ```bash
   git clone https://github.com/eh-munna/react-lab.git
   ```

2. **Navigate to the Project Directory**:
   Change into the project directory:
   ```bash
   cd react-lab
   ```
3. **Install Dependencies**:
   Use npm or yarn to install the required dependencies:
   ```bash
   npm install
   ```
   or
   ```bash
   yarn install
   ```
4. **Run the Application**:
   Start the application using the following command:
   ```bash
   npm run dev
   ```
   or
   ```bash
   yarn dev
   ```
5. **Access the Application**:
   Open your web browser and go to `http://localhost:3000` to see the application running.
